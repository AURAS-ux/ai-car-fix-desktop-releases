# Visikit releases

Visikit is a desktop application for reviewing visible car defects in images
and applying the repairs you confirm. It uses your configured AI provider;
provider access and usage charges are separate from installing the app.

This repository holds public installers, release instructions, notices,
checksums and corresponding source archives. Project development is tracked at
[the Codeberg repository](https://codeberg.org/AurasPaltanea/ai-car-fix-desktop).
That repository may require access; each public binary release supplies its
GPL corresponding source as a separate release asset.

Download files from [Releases](https://github.com/AURAS-ux/ai-car-fix-desktop-releases/releases).
Read the release's `INSTALL.md`, notes and limitations before installing.
Windows x64 and x86 installers and Linux x64 Debian/user archive packages are
planned. Test prereleases are for evaluation and remain excluded from automatic
stable update discovery. Installation tests and real app use determine tested
support; target names alone do not establish compatibility.

Installers are unsigned. SHA-256 values verify bytes against the release's
checksum record; they do not authenticate a signer. Public automatic builds
are disabled. Windows testers only download, install and use the app.

Visikit's first-party code is GPL-3.0-or-later. Each dependency retains its own
terms. The matching source archive, complete notices and rebuild instructions
accompany every binary release. GitHub's automatically generated repository
ZIP/tar files contain only this distribution metadata and are not the
application's corresponding source.
